## 0. 方法と、その限界

シラバスPDFをテキスト抽出し、ノート本文・午前Ⅱ300問と**双方向**に照合した。

| 向き | 見るもの |
|---|---|
| シラバス → ノート | 出題範囲にあってノートに無いもの（**不足**） |
| ノート → シラバス＋午前Ⅱ | ノートにあるが出題根拠が確認できないもの（**過剰**） |

**限界を先に明示する。** 機械照合は表記の揺れで誤検出する。実際、初回の照合では「プロジェクトのリスクに関する知識」のような一般句が大量に「未カバー」と判定され、416項目中312件（75%）が未カバーという無意味な数字が出た。そのため下記は**全件を手で検証し、誤検出を除いた結果**のみを載せている。

除外した誤検出の例: 「3点見積り／類推見積り」（ノートは「見積**も**り」表記で存在）、「リスク監視」（ノートは「リスク**の**監視」）、「先行関係」（ノートは「依存関係」）、「資源の管理」（ノートは「資源のコントロール」）。

## 1. 最も重要な所見 — 章立てがシラバスと対応していない

**シラバスは ISO 21500 系の「5プロセス群 × 主題」構造**（立ち上げ／計画／実行／管理／終結、計43小項目）。
**ノートは PMBOK第7版の「12パフォーマンス領域」構造。**

この不一致自体は誤りではない（IPAの出題は第6版寄りで、PMBOK軸で学ぶ方が午前Ⅱには効く）。問題は**その結果として、シラバスの一部が12カテゴリのどこにも落ちていない**こと。

## 3. 過剰 — 出題根拠が確認できない赤字

ノートの赤字ユニーク**1,312語**のうち、**シラバスにも午前Ⅱ300問にも出現しないもの 978語（75%）**。

表記差による誤検出を含む（例:「準委任契約」は誤検出。「準委任」で出題あり）。ただし抽出的に検証したところ、**下記は本当にどちらにも無い**:

| 語 | ノート内出現 | シラバス | 午前Ⅱ |
|---|---:|---|---|
| サーバントリーダーシップ | 2 | 0 | 0 |
| 職務著作 | 4 | 0 | 0 |
| 下請法 | 3 | 0 | 0 |
| 固定価格契約 | 2 | 0 | 0 |
| パフォーマンス領域 | 8 | 0 | 0 |
| プロセス・ITTO | 8 | 0 | 0 |

**誤検出を大きめに見積もって差し引いても、赤字の半数以上は一次根拠を持たない。**

ただし解釈には注意が要る。シラバスは「知的財産権に関する基本的な知識」「法的制約に関する基本的な知識」のように**抽象的な書き方**をしており、下請法・職務著作といった具体名を挙げていない。したがって「シラバスに無い＝出題されない」ではない。
**言えるのは「12年分の実出題にもシラバスの明示項目にも現れていない語に、赤字（暗記対象）の資格を与えてよいか」を再判定すべき、ということ。**

## 4. 第三者視点での総評

**良い点**
- 計画・管理系（シラバス大項目2・4）の**中核はほぼ網羅**されている。43小項目のうち、内容の欠落が確認されたのは9件のみ
- 午後Ⅰの定石は出題実績の裏付けが全件取れており、シラバスの「要求される技能」側（〜する能力）に対応する数少ない部分になっている
- 改訂済みの project-work・service-management は、シラバスの主題単位に近い粒度になった（結果的にシラバス構造へ寄った）

**弱い点**
1. **試験の言葉で書かれていない。** 供給者・品質保証・関与度・変更登録簿など、**IPAが使う語をノートが使っていない**。PMBOK訳語で統一した結果、選択肢と照合できない
2. **「立ち上げ」と「終結」が薄い。** 12カテゴリが実行・計画中心で、大項目1（立ち上げ）と5（終結）に対応する塊が無い。午後Ⅱ論述では立ち上げ・終結が主題になりうる
3. **暗記対象（赤字）の選定根拠が主観的。** 出題実績とシラバスの双方に照らすと過半が根拠を持たない

**総合**: 網羅性より**言葉の一致**と**赤字の選定**が課題。内容を足すより、**既存の記述を試験の語に寄せる**方が費用対効果が高い。
